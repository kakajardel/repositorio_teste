# repositorio_teste
Repositório de teste para envios e exclusão de arquivos da aula de versionamento.

Desenvolvido para testes de envio de arquivos e versionamentos de softwares, aonde todos os arquivos aqui 
presentes tem o intuíto de demonstração de manipulação de versão.

- Uso para guardar arquivos de projetos pessoais;
- Configurações gerais de projeto;
- Uso de integrações e manipulação de arquivos.

O uso de arquivos aqui guardados é livre.
